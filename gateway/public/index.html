On-chain commitments

Each signal's SHA-256 is written to Concordium before the outcome: one per asset every daily close, whether or not anyone buys, plus every sale. No hit rate is shown: the score is computed only from the chain and Binance by the published scoring rule, which counts duplicates and unrevealed calls as failures. This page recomputes hashes in your browser but reads transactions through this server; for a check that does not, compare the hash with the transaction on CCDExplorer.
